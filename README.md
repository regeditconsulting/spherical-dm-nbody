# dm_halo_nbody — сферически-симметричная N-body модель гало ТМ

## Постановка
- Профиль: NFW, ρ(r) = ρ0 / [(r/rs)(1 + r/rs)^2].
- Усечение: конечный r_t обязателен (иначе M → ∞). Значение фиксируется в конфиге.
- DF: изотропный f(ε); анизотропные — β-модели, Осипков–Меррит f(Q), Q = ε + ℓ²/(2 r_a²).
- Единицы и softened gravity — фиксируются в src/config (не в коде).
- G задаётся явно; никаких неявных соглашений.

## Инструменты
- NSphere (kris-sigurdson/NSphere) — сферический solver (r, vr, ℓ), N log N.
- SpheCow — восстановление DF и динамических свойств.
- galpy / собственный сэмплер — IC без зависимости от NEMO.
- SphDSMC — при переходе к SIDM.
- Gadget-4 — эталон 3D-симуляции (только кросс-проверка).

## Верификация (обязательные тесты)
1. Восстановление ρ(r) из сэмплированной DF для NFW.
2. Hernquist и Plummer с аналитической f(ε) — восстановление ρ(r) и DF.
3. Стабильность NSphere на временах, где ожидается стационарность.
